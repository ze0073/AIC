# 视界 · AI 网站质量测试平台 V0.6.0 实施与验收

日期：2026-09-23  
产品版本：`0.6.0-SNAPSHOT`  
静态规则版本：`P0-1.0+P1-0.4`

## 已实现范围

- Spring Security 会话登录、Cookie CSRF、首次本机管理员初始化；项目角色为管理员、成员、只读访问者。
- 在线目标登记、DNS 地址固定、Origin/路径校验、逐次重定向校验；静态扫描沙箱保持原样。
- AES-GCM 加密凭据，密文绑定项目、目标、凭据 ID 和 Origin；支持 Bearer 与 Cookie，列表接口仅返回指纹前缀。
- 版本化测试套件与统一运行；运行配置、检测器版本、工具镜像与本机镜像摘要进入不可变快照。
- Playwright 在线前端检查：R001–R009、JavaScript 异常、失败资源、HTTP 错误资源、最多 100 个同站链接、最多 20 步流程断言及失败截图证据。
- 页面性能固定 1440×1000 冷上下文执行三次，保存 TTFB、导航时间、请求数、声明资源体积及可获得的 LCP/CLS。
- 传输与响应配置检查：HTTPS/TLS 证书、HTTP 跳转、HSTS、CSP、Cookie 属性和混合内容。
- 登记式接口权限断言：匿名访问、角色断言、跨用户断言、凭据基准失败的无法判断处理；HTTP 200 登录页不会仅凭状态码判定越权。
- 上传入口检查使用唯一无害标记文件，分别记录错误接受、公开访问、危险响应类型和清理状态，不推导远程代码执行。
- ZAP Automation Framework 使用独立容器，请求播种仅针对明确标记 `activeScan` 的 GET 接口及登记的查询参数；只启用规则 40012（反射型 XSS）和 40018（SQL 注入），最多 10 个登记接口，主动扫描上限 9 分钟。
- k6 独立容器执行阶梯负载，硬限制 20 VU、120 秒、每秒最多 50 次请求；按配置速率控制每个 VU 的请求间隔，保存 P50/P95/P99、吞吐、错误率和 10 秒窗口时间序列。预热后连续两个完整 10 秒窗口错误率超过 20% 时停止容器并保留部分结果。
- 修复任务、负责人、评论与历史；“已验证”必须关联同项目完整复测，且复测不得再次出现同一问题键。
- 知识案例草稿、发布门槛与关键词检索；每日回归计划在数据库恢复，默认不运行主动扫描、上传与负载，上传须单独明确启用。
- 相同目标、相同套件版本在一次完整通过后再次出现已验证问题时，重新打开任务并生成站内提醒；无法判断和配置风险不触发复发。
- Qwen 使用脱敏问题证据和最多 3 个项目案例解释原因；未启用或失败时返回规则说明，不影响检测。
- 统一运行 PDF/JSON 来自同一 `schemaVersion=0.6.0` 不可变快照并校验 SHA-256。
- 独立校园报名应用支持 `defective`、`fixed`、`regression` 三种模式，使用独立 MySQL 与无害上传清理接口。

## 结果口径

无障碍内部风险分、安全等级/复核状态和性能阈值分别展示，不合成跨模块总分。ZAP 输出初始为引擎候选；权限与流程断言是可复现断言；HSTS、CSP、Cookie 等是配置风险。任何未执行、超时、取消、凭据失效或网络异常均不得显示为通过。

## 边界与后续核验

- 本次真实目标是本机 HTTP 演示应用，未用真实 HTTPS 站点验证证书/HSTS/混合内容分支。HTTPS 目标的 HTTP 跳转探测若未另行登记 HTTP Origin，会明确显示“未测试”，不会跨出授权范围。
- 登记时及请求前会核对目标解析和 Origin/路径；Docker 工具的实际 DNS 解析尚未做到跨请求强制钉住。仅在可信、隔离的目标网络使用主动扫描和负载工具。
- 真实三次运行验证了正常完成、修复复测与复发链路；高错误率提前终止及每日计划自动触发有单元/逻辑覆盖，但没有在这三次演示中产生对应的端到端样本。
- 演示应用和数据库默认仅绑定本机回环地址。容器工具需要访问演示应用时，短时间开放宿主机地址只能在隔离实验环境进行，结束后应恢复回环绑定。
