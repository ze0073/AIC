## 本轮已接通

- 测试中心支持从当前套件版本填充表单、修改并发布下一版本；VU 阶梯、阶段时长、速率上限、P95 和错误率阈值开放配置。旧运行仍引用原版本。
- 问题可人工确认或驳回；理由必填，记录操作者和历史，复核结论不改变修复任务状态。AI 在线解释可选，离线规则解释明确标识，不能代替复核。
- 回归计划支持上传开关、配置更新、启停。计划仍绑定创建时的套件版本，发布新版本不会暗中替换。
- 测试中心运行记录增加状态/模块筛选、分页和地址栏状态保存；运行中的问题可直接跳转到对应人工复核表单。
- 运行详情按模块展示页面指标、接口检查、P50/P95/P99、吞吐、错误率、时间序列、首次超阈值阶段；原始 JSON 仅作高级证据。
- 同项目、同目标、同套件版本、同负载配置的运行对比，逐模块要求两次均完整执行；缺失、异常、无法判断明确返回不可比原因。
- 新报告使用不可变 `schemaVersion=0.6.1` JSON 快照，PDF 展示范围、工具版本、负载配置、性能、人工复核、复测与复发关联，保留同一 SHA-256。旧 0.6.0 快照原样保留。
- 运行详情的 PDF/JSON 导出固定在已选 0.6.1 快照，刷新后仍沿用该快照；即使其他成员插入较新的快照，两种格式也不会错配。复核状态变化后可显式生成新快照，页面显示当前快照哈希。
- Java 请求使用限制为目标主机的自定义 DNS 解析器；Chromium 使用主机解析规则，并由受限 Java 请求通道逐次代发浏览器请求和校验跳转；ZAP/k6 容器使用 `--add-host`。仍在每次请求前检查 DNS、Origin 与路径；Java 与 k6 不自动跟随重定向。工具部分失败会保留已取得模块结果。
